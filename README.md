# IA Brains de Chatty

Presentación pública de un prototipo local para explorar conocimiento documentado y consultarlo mediante una IA ejecutada en el mismo ordenador.

## Ver la presentación

La versión publicada funciona como una presentación web de siete diapositivas. Se puede recorrer con los botones de navegación, las flechas del teclado o las teclas `Page Up` y `Page Down`.

## Qué muestra

- El problema de localizar funciones, documentación y proyectos dispersos.
- Una interfaz que combina mapa, búsqueda y conversación.
- Una arquitectura local con un índice separado y procedencia revisable.
- La jerarquía de agentes que organiza la construcción web.
- Los límites entre material documentado, carpetas disponibles y memoria privada.
- El estado comprobado del prototipo en la fecha indicada.

## Privacidad y alcance

Este repositorio contiene solo la presentación y dos imágenes conceptuales. No contiene el código de IA Brains de Chatty, bases de datos, catálogos locales, rutas del equipo, recuerdos privados, prompts de agentes ni contenido de otros proyectos.

Las imágenes son conceptuales y fueron generadas con IA. No son capturas del producto ni pruebas de funcionamiento. La presentación identifica esa condición en las diapositivas donde aparecen.
